# 路由示例与行为自查

这些是供执行者核对决定边界的场景，不是已跑过的渲染基准。输出应说明选择理由、依赖和证据，不用精确命中库名作为唯一成功标准。

## 高地笔记：同一体验可用不同层实现

输入：深绿暖金不改；首页咖啡树；点豆缩小并显示档案；进入新界面；处理站真 3D、旋转、点设施看六道工序；建筑先精简。

合理路由：

- 首页树：现有 Canvas 2D 已能实现就沿用；少量需要键盘选中的豆用 DOM/SVG 热区或提供等价按钮，不为一棵线描树直接引 WebGL。
- 档案与转场：CSS/WAAPI 可完成则直接采用；已有复杂时间轴时复用 GSAP；相机/场景状态与 DOM 卡片分开。
- 处理站：Three.js + 匹配版本 controls/raycast，按实际版本确认 GPU 后端；过渡时协调 controls，退出释放场景资源。
- 降级：静态处理站图 + 六道工序的 DOM 列表，保持返回与档案路径。低性能先降低阴影/像素比和对象复杂度，再考虑换方案。
- 参赛视频若另有要求：真实操作录屏作为证据，Remotion 或 HyperFrames 编排说明；Seedance 可选的氛围镜头不能冒充站点运行。

示例决定卡：`FX-03 | 访谈“真3D可旋转” | 实时场景 | Three.js | 未选视频：不能任意旋转/拾取 | 小样：拖拽、点击晾晒床、返回并再次进入 | 未测移动端则明确待验`。

## 其他边界

| 输入 | 应出现的决定 | 应避免 |
|---|---|---|
| 只改按钮 hover，现有 CSS | 直接指定属性 transition，focus 即时可见 | 全套访谈、装 GSAP/WebGL |
| React 列表已有 Motion，筛选与退出动画 | 复用现有生命周期，验证快速切换 | 再引同类驱动抢写 transform |
| 长页章节和相机联动滚动叙事 | 比较原生方案与 GSAP，评估滚动/减少动效退路 | 没理由装全套图形库、锁住键盘滚动 |
| 想要“电影感”，但必须随鼠标探索 | 澄清真实交互程度，选择实时场景或分层混合 | 用生成视频替代交互承诺 |
| 30 秒视频，数据从 JSON 更新，现有 React | 评估 Remotion；帧率/时长/数据与导出验收 | 宣称是实时业务系统 |
| HTML 技术栈的产品短片，已有 HyperFrames | 复用 HTML composition 与可 seek 时间轴 | 原样抓网页，假设每帧都确定 |
| 需要不存在的咖啡山地氛围镜头 | Seedance 服务可用且有授权才生成；否则给素材方案 | 虚构 API 调用、生成价格或真实产地证据 |
| 无 GPU/无法联网/缺视频工具 | 分别走静态+DOM/本地资产/未渲染交付 | 把缺工具写成测试通过 |
| 已有品牌和完整方案 | 继承并做必要选型 | Hallmark 强制随机主题或替换用户字体 |

交接必须能回答：这项技术对应哪条用户决定？删掉动效后核心任务还在吗？遇到失败走哪里？哪些结论有运行证据，哪些只是计划？

## v5.1 反例走查

- 没有 .riv、没有资产制作条件：给 DOM/SVG 简化版或待制作项，不把 Rive 路由标已实现。
- 要用原生 View Transitions，但目标能力不支持：保持单次业务更新并直接切换；不装第二个动画库作为默认补救。
- 处理站由程序几何构成：先查对象/阴影/DPR 成本，不为不存在的 GLB 安装压缩工具。
- GLB 优化后体积更小但拾取失效：不能验收通过；恢复原始映射或调整变换并重验。
- Vue 项目要三维：直接评估已有引擎，不因 R3F 新分支迁移 React。
- 风味比较只有少量演示值：先解释尺度和演示属性，用合适表格/图形，不凭动画推断真实品质。
