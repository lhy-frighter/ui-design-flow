# 启动与交接模板

按实际需要使用，不要把全部模板当固定问卷。

## 新设计 / 完整重设计

```text
请用 design-flow 完成【项目/页面】的设计与实现。
产品与主要用户：【】
最重要的任务和当前问题：【】
范围 / 必须保留 / 明确不要：【】
已有品牌、参考与喜欢的具体部分：【】
技术和设备要求：【未知的请先查项目】
完成标准：【】

先读项目与已有决定，再用 grill-me 深入澄清会改变结果的未知项。
默认一次一问，问题给具体取舍和推荐；能查的事实自己查。
方向开放时用相同真实内容比较两种不同结构，再落实方向约定和设计系统。
从代表页与核心路径开始实现，实际打开页面，按评审手册修复并验证。
缺少工具如实标记，不虚构用户回答、截图观察或测试结果。
```

## 参考改版

```text
请在【项目】改进【页面】。
参考：【链接/图/文件】
我想借用：【比例/字体层级/节奏/组件机制等】
我不想继承：【】
现有产品必须保留：【】
我说的「高级」更接近：【具体感受或实例；未知可先帮我定位】

先区分参考的可见事实与未知信息，做紧凑的继承/改造/舍弃表。
方向明确后实现，不为套风格改变真实内容与核心任务。
对照参考继承表、产品目标分别复核，交付可运行结果和实际验证记录。
```

## 定向打磨

- **太像模板**：指出可以替换 logo 就套用其他产品的区域，依据本产品内容改一处结构或主体表达；保持清楚的操作路径。
- **太花**：从任务顺序与视觉重心出发削减竞争；保留已确认的品牌特征，不一刀切成灰白。
- **不够高级**：定位排版、比例、密度、色彩、材质、资产中影响最大的项，先改代表片段并复核；不默认加玻璃和金色。
- **看板太乱**：按用户比较与决策顺序重排，验证长内容与大量数据；不套营销 hero。
- **细节粗糙**：检查真实换行、基线、图标、边界、焦点、状态切换与缩放；列出实际差异。
- **没问我就做方向**：读取现有决定，只重开未获授权的关键分歧；不要重新询问全部已定内容。

## DESIGN.md 最小约定

```markdown
## 目标与范围
主要用户、核心任务、受影响页面、不可改项、成功标准。

## 访谈定案
用户决定 / 已查事实 / agent 决定分别写明；暂定假设列影响和验证时机。

## 方向约定
概念、内容顺序、构图、字体角色、色彩/材质、主体表达、否定项与成本。

## 设计系统
沿用/修改的语义 tokens、组件族、页级例外和状态。

## 验证与交接
启动方式、截图路径与路由/视口/主题/状态、已验项、未验项及影响、下一步。
```

主 agent 合并到已有文档，保留有效历史。无需强迫所有项目采用同一编号或文件拆分方式。

## 动效/图形/视频技术决定补充

```text
用户已定方向/自有想法：【】
输出：可交互网页 / 视频 / 两者
效果与对应访谈决定：【】
触发、对象、终态与中断：【】
精确内容、目标设备与现有技术：【先检查项目】
请在 DESIGN.md 记录主方案、备选及取舍、资产/版本核查、成本、退路和验证证据。
先验证风险最高的一个片段，再实现其他页面；不要把生成镜头当作真实操作证据。
```
